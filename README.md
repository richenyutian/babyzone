# Baby Steps - 极简宝宝成长相册 PRD

## 1. 项目概述

- **目标**：为新生儿父亲打造的极简、私密、易部署的图文记录 Web 应用。
- **核心理念**：去社交化、专注记录、极简美学、数据自主。
- **设计风格**：Style A - 极简清新（大留白、细线条、Apple 风格）。

## 2. 技术栈要求

- **后端**：Java 17+, Spring Boot 3.x。
- **数据库**：SQLite（单文件数据库，存储在项目根目录 `data/` 下）。
- **前端**：Vue 3 或 React，使用 Tailwind CSS 进行样式开发。
- **存储**：图片直接存储在服务器本地磁盘。
- **部署**：支持 Docker 及 Docker Compose 一键启动（包含自动挂载数据卷以防丢失）。

## 3. 功能需求

### 3.1 核心逻辑：成长统计

- **出生设置**：系统初始化或配置文件中设置宝宝生日（`YYYY-MM-DD`）。
- **实时计算**：首页顶部显著位置显示宝宝当前的“出生天数”及“当前月龄”（例如：100天，3个月10天）。

### 3.2 记录功能（MVP）

#### 图文发布

- 上传照片（支持单张或多张）。
- 文字内容（支持 Markdown 或纯文本）。
- 日期选择（默认为今天）。
- 标签/分类（可选，如：第一次、生病、出游）。

#### 时光轴展示

- 首页以垂直时间轴展示。
- 每条记录为一个卡片，包含照片预览、文字片段和精准的“宝宝当时月龄”。

### 3.3 管理与安全

- **身份验证**：极简后台登录（固定账号密码或简单配置文件指定），仅限管理员操作。
- **数据迁移**：系统所有的配置、数据库文件、照片均存放在一个指定的根目录下，方便整体打包迁移。

## 4. UI/UX 规范（Cursor 参考）

- **色调**：以白色（`#FFFFFF`）为主背景，点缀极浅灰（`#F9FAFB`）和莫兰迪色系的温暖点缀。
- **字体**：系统默认无衬线字体，保持排版疏朗。
- **响应式**：必须完美适配手机端，方便父亲随时在手机上翻看。

## 5. 数据库设计（SQLite）

### `settings` 表

用于存储宝宝生日、姓名、登录密码。

### `records` 表

字段：

- `id`
- `content`
- `date`
- `create_time`
- `update_time`

### `photos` 表

字段：

- `id`
- `record_id`
- `file_path`
- `file_name`
