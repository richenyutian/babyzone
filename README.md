# report-tool

一个用于运维工单数据的灵活报表工具，支持按自定义 SQL 查询数据并渲染报表。

## 功能概览

1. **API 配置**
   - 支持配置请求方式（GET/POST）、请求 Cookie、超时时间、目标地址。
2. **报表配置**
   - 支持配置报表名称、表头、报表类型（柱状图/饼图/表格）、报表 SQL 以及关联 API。
3. **报表查看**
   - 自动执行报表 SQL，通过 API 查询数据并渲染目标样式。

## 技术栈

- Vue2
- Element UI2
- SQLite
- Express

## 启动方式

```bash
npm install
npm run dev
```

启动后访问：`http://127.0.0.1:3000`

## 默认数据

- 内置示例工单数据（tickets）
- 内置默认 API 配置
- 内置 3 个示例报表（饼图、柱状图、表格）

## SQL 规则限制

出于安全考虑，报表 SQL 和查询接口仅允许 `SELECT` 或 `WITH` 开头的只读语句。
